# data-studio-workshop

## Overview

A 5-page interactive dashboard created using Google Looker Studio as part of a "Data to Insights: Build Interactive Dashboards with Data Studio" workshop assignment. The report covers student performance, course scores, revenue, and sales trends.

## Key Insights
7,423 student records were analyzed, with an average mark of 42.13 out of 100.
The largest student group falls in the 40–49 marks range (15.6%), followed by 30–39 (15.1%).
The course analysis compares Quiz 1, Quiz 2, and End Exam scores for individual students.
Laptop revenue is highest at $1,000, followed by Mobile ($550) and Tablet ($400).
The revenue table shows Mouse ($40) and Keyboard ($60) as the lowest-revenue products.
The final page visualizes sales trends for Pants, Shirts, and Other category over time.

## Visualizations
- Marks distribution using bar chart
- Student distribution by marks using pie chart
- Pivot table for course scores
- Scatter plot comparing Quiz 2 and End Exam scores
- Revenue table by product
- Sales trend line charts for Pants, Shirts, and Other categories
